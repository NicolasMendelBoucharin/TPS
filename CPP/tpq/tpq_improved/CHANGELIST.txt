🔴 BUGS CRITIQUES CORRIGÉS
================================================================================

1. BUG GAUSS - Swap incorrect du vecteur B
   Fichier     : src/matrice.cpp, ligne 302
   Problème    : b.set(i, b.get(piv)) manquait un argument
   Correction  : Ajout d'une variable temporaire pour le swap
   Impact      : Plantage lors de l'élimination de Gauss
   Statut      : ✅ CORRIGÉ

2. FICHIERS NON FERMÉS
   Fichier     : src/main.cpp, fin du programme
   Problème    : 3 fichiers ouverts mais jamais fermés
   Correction  : Ajout de .close() pour chaque flux
   Impact      : Fuite de ressources, fichiers verrouillés
   Statut      : ✅ CORRIGÉ

3. PAS DE VÉRIFICATION OUVERTURE FICHIER
   Fichier     : src/main.cpp, lignes ~22-30
   Problème    : Aucun check si fichiers existent
   Correction  : if (!fichier.is_open()) throw exception
   Impact      : Crash silencieux avec fichiers manquants
   Statut      : ✅ CORRIGÉ

4. BUG QQ::POW() - Utilisation de std::pow
   Fichier     : src/qq.cpp, ligne 170
   Problème    : std::pow retourne double, perte de précision
   Correction  : Boucle d'itération avec opérateur * de qq
   Impact      : Résultats inexacts pour puissances de rationnels
   Statut      : ✅ CORRIGÉ
